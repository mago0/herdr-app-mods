# herdr-app-mods

Add-ons for [Herdr.app](https://herdr.dev): mods for its window and the tools behind them.

| Mod | What it does |
|---|---|
| [pr-watch](pr-watch/) | PRs each agent opened, rolled up to its parent, and a watch that wakes the owning agent when a PR needs action. |
